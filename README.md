# Proposta PT São Miguel

Landing page da proposta de comunicação digital para o Diretório Municipal do PT
de São Miguel das Missões.

Página única, sem dependências, em tema claro fixo. Publicada pelo GitHub Pages a
partir da branch `main`, pasta raiz.

- `index.html` - a página inteira, com CSS embutido e cores escritas em valor
  literal. Fontes carregadas do Google Fonts, com pilha de reserva.

## Conteúdo

Três pacotes por número de publicações (5, 10 ou 15), a lista do que está incluso
na montagem do perfil e a explicação do que conta como uma publicação, que pode
ser um carrossel ou um vídeo.

Escopo sem tráfego pago, a pedido do cliente.
