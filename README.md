# Proposta PT São Miguel

Landing page da proposta de comunicação digital para o Diretório Municipal do PT
de São Miguel das Missões.

Página única, sem dependências. Publicada pelo GitHub Pages a partir da branch
`main`, pasta raiz.

- `index.html` - a página inteira, com CSS embutido. Fontes carregadas do Google Fonts.

## Conteúdo

Três pacotes por volume de publicação (5, 10 ou 15), a lista do que está incluso
na montagem do perfil, a explicação do que conta como uma publicação (carrossel
ou vídeo) e a regra de quem contrata o impulsionamento.
